# Contact The fastest way to reach the maintainers is through the project's GitHub repository. There is no email inbox, phone line, or office for this project — it is a solo open-source effort and all communication happens in public. ## Bug reports and feature requests Open an issue at [github.com/riceharvest/llm-prefill-decode-visualizer/issues](https://github.com/riceharvest/llm-prefill-decode-visualizer/issues). Please include: - The exact URL or API request that misbehaves - What you expected vs what you saw - For wrong numbers: the hardware preset, model, and speeds involved ## API and integration questions Read [/llms.txt](/llms.txt) first — it answers most agent and scripting questions, including markdown content negotiation (`Accept: text/markdown`) and the versioned `/v1/` prefix policy. The [OpenAPI spec](/api/spec) documents every parameter of every endpoint. ## Security issues Do not open a public issue for security vulnerabilities. Use GitHub's private security advisory feature on the repository instead. ## Data corrections Benchmark rows come from the [LocalMaxxing](https://www.localmaxxing.com) community dataset. If a run attributed to your hardware is wrong, correct it at the source (localmaxxing.com) and the change flows into this site's cached index within the refresh window. ## Response time This is a side project; issue responses typically land within a few days. There are no SLAs. See also: [About](/about.html) · [Privacy](/privacy.html)
